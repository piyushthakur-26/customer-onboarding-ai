# Customer Onboarding AI

AI-powered multi-agent customer onboarding platform.

## Project Overview

This project uses multiple AI agents to automate and assist with customer onboarding, including document processing, KYC verification, compliance checks, and fraud/risk assessment.

## Planned Technologies

- Python
- FastAPI
- LangGraph
- PostgreSQL
- RAG
- Vector Database
- LLM APIs
- React
- Docker
- GitHub
